## Lists in Python

A list is a built-in Python data type used to store multiple values in a single variable. Lists are **ordered, mutable**, and allow duplicate values and different data types.

```python
l1 = [7, 9, "harry"]
print(l1)
# Output: [7, 9, 'harry']
```

Lists are mutable, which means their elements can be modified after creation.

```python
l1 = [10, 20, 30]
l1[1] = 50
print(l1)
# Output: [10, 50, 30]
```

## List Indexing

List indexing works similarly to string indexing. The first element has index `0`, and negative indexing starts from the end of the list.

```python
l1 = [7, 9, "harry"]

print(l1[0])   # Output: 7
print(l1[1])   # Output: 9
print(l1[-1])  # Output: harry
```

Accessing an index outside the valid range raises an `IndexError`.

```python
print(l1[70])
# Output: IndexError
```

## List Slicing

Slicing extracts a portion of a list using the syntax `list[start:stop:step]`. The start index is included, but the stop index is excluded.

```python
l1 = [10, 20, 30, 40, 50]

print(l1[0:2])  # Output: [10, 20]
print(l1[1:4])  # Output: [20, 30, 40]
print(l1[:3])   # Output: [10, 20, 30]
print(l1[2:])   # Output: [30, 40, 50]
print(l1[::-1]) # Output: [50, 40, 30, 20, 10]
```

## List Methods

Consider the following list:

```python
l1 = [1, 8, 7, 2, 21, 15]
```

**`sort()`**

Sorts the list in ascending order by default.

```python
l1.sort()
print(l1)
# Output: [1, 2, 7, 8, 15, 21]
```

**`reverse()`**

Reverses the current order of elements.

```python
l1.reverse()
print(l1)
# Output: [15, 21, 2, 7, 8, 1]
```

**`append()`**

Adds an element to the end of the list.

```python
l1.append(8)
print(l1)
# Output: [1, 8, 7, 2, 21, 15, 8]
```

**`insert()`**

Inserts an element at the specified index.

```python
l1.insert(3, 8)
print(l1)
# Output: [1, 8, 7, 8, 2, 21, 15]
```

**`pop()`**

Removes and returns the element at the specified index. If no index is provided, it removes the last element.

```python
l1 = [1, 8, 7, 2, 21, 15]

print(l1.pop(2))  # Output: 7
print(l1)         # Output: [1, 8, 2, 21, 15]
```

**`remove()`**

Removes the first occurrence of the specified value.

```python
l1 = [1, 8, 7, 2, 21, 15]
l1.remove(21)
print(l1)
# Output: [1, 8, 7, 2, 15]
```

## Tuples in Python

A tuple is a built-in Python data type used to store multiple values. Tuples are **ordered and immutable**, meaning their elements cannot be changed after creation. They can contain duplicate values and different data types.

```python
a = ()           # Empty tuple
b = (1,)         # Tuple with one element
c = (1, 7, 2)    # Tuple with multiple elements
d = (1, "hello", 3.5)

print(c)
# Output: (1, 7, 2)
```

A single-element tuple requires a trailing comma. Without it, Python treats the expression as a regular value.

```python
a = (1,)
print(type(a))  # Output: <class 'tuple'>

b = (1)
print(type(b))  # Output: <class 'int'>
```

### Tuple Indexing and Slicing

Tuples support indexing and slicing in the same way as lists.

```python
a = (10, 20, 30, 40, 50)

print(a[0])     # Output: 10
print(a[-1])    # Output: 50
print(a[1:4])   # Output: (20, 30, 40)
```

Tuples cannot be modified after creation.

```python
a = (1, 2, 3)
a[0] = 10
# Output: TypeError
```

## Tuple Methods

Consider the following tuple:

```python
a = (1, 7, 2, 1, 5, 1)
```

**`count()`**

Returns the number of times a specified value occurs in the tuple.

```python
print(a.count(1))
# Output: 3
```

**`index()`**

Returns the index of the first occurrence of a specified value.

```python
print(a.index(7))
# Output: 1

print(a.index(1))
# Output: 0
```

If the specified value does not exist, `index()` raises a `ValueError`.

## Lists vs Tuples

| Feature | List | Tuple |
|---|---|---|
| Syntax | `[1, 2, 3]` | `(1, 2, 3)` |
| Mutable | Yes | No |
| Indexing | Supported | Supported |
| Slicing | Supported | Supported |
| Methods | Multiple methods | `count()`, `index()` |
| Typical use | Data that changes | Data that should remain fixed |

## Key Takeaways

- Lists store multiple values and allow modification.
- Tuples store multiple values but do not allow modification.
- Both support indexing, negative indexing, slicing, and duplicate values.
- List methods such as `append()`, `insert()`, `remove()`, `pop()`, `sort()`, and `reverse()` modify the list in place.
- Tuple methods `count()` and `index()` help find occurrences and positions of elements.

## Overview

Data types define what kind of value a variable stores and how it can be used. In Python, they help organize information such as IP addresses, ports, logs, network packets, and scan results.

## Strings (`str`)

Strings store text, such as usernames, URLs, and hostnames.

```
ip = "192.168.1.10"
service = "SSH"

print(ip)
print(service)
print(ip[0])   # First character: 1
print(ip[-1])  # Last character: 0
```

Strings are **immutable**, meaning their characters cannot be changed directly.

## Integers (`int`) and Floats (`float`)

Integers represent whole numbers, while floats represent decimal numbers.

```
port = 443
latency = 0.534

print(port)
print(latency)
print(port + 1)
print(latency * 2)
```

## Booleans (`bool`)

Booleans represent `True` or `False`.

```
is_online = True

if is_online:
    print("Target is online")
```

## Lists (`list`)

Lists store multiple values in an ordered, changeable collection.

```
ports = [22, 80, 443]

print(ports[0])   # First item: 22
print(ports[1])   # Second item: 80
print(ports[-1])  # Last item: 443

ports[0] = 21
ports.append(8080)

print(ports)
```

Indexing starts at `0`. Negative indexing starts from the end, with `-1` representing the last item.

Lists are **mutable**, meaning their contents can be changed.

## Tuples (`tuple`)

Tuples store ordered values but cannot be modified after creation.

```
target = ("192.168.1.10", 443)

print(target[0])
print(target[1])
```

Tuples are immutable.

## Sets (`set`)

Sets store unique values and automatically remove duplicates.

```
ports = {22, 80, 80, 443}

print(ports)
ports.add(8080)
```

Sets are mutable, but their elements must be hashable. Sets do not support indexing.

## Dictionaries (`dict`)

Dictionaries store information as key-value pairs.

```
target = {
    "ip": "192.168.1.10",
    "port": 443,
    "online": True
}

print(target["ip"])
print(target["port"])

target["port"] = 8080
```

Dictionaries are mutable. Access values using their keys rather than positional indexes.

## Bytes (`bytes`)

Bytes represent raw binary data, often used in networking and file handling.

```
data = b"Hello"

print(data[0])  # 72 (ASCII value of H)
print(data.decode())  # Hello
```

Bytes are immutable. The `decode()` method converts bytes into text when the encoding is valid.

## NoneType (`None`)

`None` represents the absence of a value.

```
session = None

if session is None:
    print("No active session")
```

## Mutable vs Immutable

**Mutable** objects can be changed after creation. **Immutable** objects cannot be changed after creation.

|Type|Mutable?|
|---|---|
|`str`|No|
|`int`|No|
|`float`|No|
|`bool`|No|
|`list`|Yes|
|`tuple`|No|
|`set`|Yes|
|`dict`|Yes|
|`bytes`|No|
|`NoneType`|No|

Example:

```
ports = [22, 80]
ports[0] = 443
print(ports)  # [443, 80]

name = "Kali"
# name[0] = "M"  # Raises TypeError
name = "Mali"    # Creates a new string value
```

## Combining Data Types

```
result = {
    "ip": "192.168.1.10",
    "ports": [22, 80, 443],
    "online": True,
    "latency": 0.34,
    "session": None
}

print(result["ip"])
print(result["ports"][0])
print(type(result["online"]))
```

Use `type()` to identify a value's data type.

## Quick Practice

```
targets = ["192.168.1.10", "192.168.1.20"]

print(targets[0])
print(targets[-1])

targets.append("192.168.1.30")
print(targets)

print(type(targets))
```

Understanding indexing and mutability helps you access, update, and process data correctly when building Python scripts for automation and cybersecurity.

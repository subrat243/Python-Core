## What is Data type?

Data types define what kind of value a variable contains and determine how that value can be used in a program.

When writing scripts that work with targets, ports, logs, requests, credentials, packets, and scan results, choosing the correct data type makes the code easier to understand and process.

## Strings

A string (`str`) stores text.

Strings can contain usernames, URLs, hostnames, log entries, commands, or payloads.

```
payload = "' OR 1=1 --"

print("Payload:", payload)
```

Output:

```
Payload: ' OR 1=1 --
```

Strings can also be used for addresses and service names:

```
ip_address = "192.168.1.10"
service = "SSH"

print(f"Target: {ip_address}")
print(f"Service: {service}")
```

Common uses include URLs, log messages, wordlists, usernames, and other text-based data.

---

## Integers

An integer (`int`) represents a whole number.

Port numbers, counters, process IDs, and retry limits are common examples.

```
port = 443
attempts = 3

print(f"Port: {port}")
print(f"Attempts: {attempts}")
```

Output:

```
Port: 443
Attempts: 3
```

Integers can also be used in calculations:

```
start_port = 20
end_port = 25

print(end_port - start_port)
```

---

## Floats

A float (`float`) represents a number containing a decimal value.

They are useful for response times, latency, delays, and measurements.

```
response_time = 0.534

print(f"Response time: {response_time} seconds")
```

A simple condition can be used to classify a response:

```
latency = 1.25

if latency > 1.0:
    print("High Latency")
else:
    print("OK")
```

---

## Booleans

A Boolean (`bool`) has only two possible values:

```
True
False
```

Booleans are useful when representing states such as whether a host is reachable or whether a service is available.

```
is_alive = True

if is_alive:
    print("Target is up")
```

Another example:

```
login_successful = False

if login_successful:
    print("Login successful")
else:
    print("Login failed")
```

---

## Lists

A list (`list`) stores multiple values in an ordered and changeable collection.

```
targets = [
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.30"
]

for ip in targets:
    print(f"Target: {ip}")
```

Output:

```
Target: 192.168.1.10
Target: 192.168.1.20
Target: 192.168.1.30
```

Lists can also contain numbers:

```
ports = [22, 80, 443]

for port in ports:
    print(f"Port: {port}")
```

Lists are useful when working with collections of targets, ports, usernames, URLs, or results.

---

## Tuples

A tuple (`tuple`) is an ordered collection that cannot be changed after creation.

```
target = ("192.168.1.10", 443)

print("IP:", target[0])
print("Port:", target[1])
```

Output:

```
IP: 192.168.1.10
Port: 443
```

Because tuples are immutable, this is not allowed:

```
target[0] = "192.168.1.20"
```

Tuples are useful when representing fixed groups of related values, such as an IP address and port.

---

## Sets

A set (`set`) stores unique values and automatically removes duplicates.

```
ips = {
    "192.168.1.10",
    "192.168.1.10",
    "192.168.1.20"
}

print(ips)
```

The duplicate IP is automatically removed.

Sets are useful when processing large collections of results where duplicate values need to be eliminated.

Two sets can also be combined:

```
internal_ips = {"192.168.1.10", "192.168.1.20"}
external_ips = {"10.0.0.5", "10.0.0.10"}

all_ips = internal_ips.union(external_ips)

print(all_ips)
```

---

## Dictionaries

A dictionary (`dict`) stores data as key-value pairs.

Dictionaries are useful for representing structured information.

```
target = {
    "ip": "192.168.1.10",
    "port": 443,
    "service": "HTTPS"
}

print(target["ip"])
print(target["port"])
print(target["service"])
```

Output:

```
192.168.1.10
443
HTTPS
```

A dictionary can contain different data types:

```
scan_result = {
    "ip": "192.168.1.10",
    "ports": [22, 80, 443],
    "online": True,
    "latency": 0.34
}

print(scan_result)
```

This makes dictionaries useful for storing structured results, configuration, HTTP information, and system details.

---

## Bytes

The `bytes` type represents raw binary data.

It is useful when working with network data, files, encoded content, and raw requests.

```
data = b"GET / HTTP/1.1\r\nHost: example.com\r\n\r\n"

print(data)
```

Output:

```
b'GET / HTTP/1.1\r\nHost: example.com\r\n\r\n'
```

A normal string can be converted into bytes:

```
message = "Hello"

data = message.encode()

print(data)
```

Output:

```
b'Hello'
```

Bytes can be converted back into a string using `decode()`:

```
data = b"Hello"

message = data.decode()

print(message)
```

Bytes are particularly important when handling raw network communication, binary files, encoded data, and cryptographic operations.

---

## NoneType

`None` represents the absence of a value.

It is useful when a value is not currently available or a variable has not been assigned meaningful data.

```
session = None

if session is None:
    print("No active session")
```

Output:

```
No active session
```

A function may also return `None` when it does not produce a result.

---

## Combining Multiple Data Types

Real programs often use several data types together.

```
scan_result = {
    "ip": "192.168.1.5",
    "ports": [22, 80, 443],
    "status": True,
    "latency": 0.34,
    "banner": b"SSH-2.0-OpenSSH",
    "session": None
}

print(scan_result)
```

Here:

```
ip        -> str
ports     -> list
status    -> bool
latency   -> float
banner    -> bytes
session   -> NoneType
```

This approach allows different pieces of information to be represented naturally within a single structure.

---

## Practical Example

The following example combines several data types into a small result-processing script:

```
targets = ["192.168.1.10", "192.168.1.20"]  # A list of target IP strings.

ports = [22, 80, 443]  # A list of integer port numbers.

results = {
    "192.168.1.10": {
        "online": True,  # A Boolean indicating whether the target responded.
        "latency": 0.21  # A float measuring response time in seconds.
    },
    "192.168.1.20": {
        "online": False,
        "latency": None  # None indicates that no response time is available.
    }
}

for target in targets:
    status = results[target]["online"]  # Read this target's online status.
    latency = results[target]["latency"]  # Read its response time, if available.

    print(f"Target: {target}")
    print(f"Online: {status}")
    print(f"Latency: {latency}")
    print()
```

Example output:

```
Target: 192.168.1.10
Online: True
Latency: 0.21

Target: 192.168.1.20
Online: False
Latency: None
```

This demonstrates how lists, dictionaries, strings, booleans, floats, and `None` can work together.

## Takeaway

Understanding Python data types is essential because different kinds of information require different ways of storing and processing them.

Strings handle text, integers handle whole numbers, floats handle measurements, booleans represent states, lists and tuples group values, sets remove duplicates, dictionaries organize structured information, bytes handle raw data, and `None` represents the absence of a value.

Once these types become familiar, they can be combined to build scripts that process targets, network information, logs, requests, and structured results efficiently.

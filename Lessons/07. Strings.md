## What Is a String?

A string (`str`) is a data type in Python used to store text. It is a sequence of characters enclosed in single quotes, double quotes, or triple quotes.

```
a = 'harry'
b = "harry"
c = '''harry'''

print(a)
print(b)
print(c)
```

All three variables store the same text.

Triple quotes can also be used to create multiline strings.

## String Indexing

Each character in a string has an index. In Python, positive indexing starts at `0`, while negative indexing starts at `-1` from the end.

```
name = "harry"

print(name[0])   # h
print(name[1])   # a
print(name[4])   # y

print(name[-1])  # y
print(name[-2])  # r
```

For `"harry"`, the positive indices range from `0` to `4`, and the negative indices range from `-5` to `-1`.

## String Slicing

String slicing extracts a portion of a string using the following syntax:

```
string[start:end]
```

The start index is included, but the end index is excluded.

```
name = "harry"

print(name[0:3])  # har
print(name[1:3])  # ar
print(name[0:5])  # harry
```

You can also omit the start or end index.

```
word = "amazing"

print(word[:7])  # amazing
print(word[0:])  # amazing
print(word[:])   # amazing
```

Negative indices can be used in slicing as well.

```
word = "python"

print(word[-3:])  # hon
print(word[:-2])  # pyth
```

## Slicing With a Skip Value

A third value can specify the step size in a slice.

```
string[start:end:step]
```

The step determines how many positions to move between characters.

```
word = "amazing"

print(word[1:6:2])  # mzn
print(word[::2])    # aaig
print(word[::-1])   # gnizama
```

A step of `2` selects every second character, while `-1` reverses the string.

## Common String Functions

### `len()`

Returns the number of characters in a string.

```
name = "harry"
print(len(name))  # 5
```

### `endswith()`

Checks whether a string ends with the specified text. Returns `True` or `False`.

```
name = "harry"
print(name.endswith("rry"))  # True
print(name.endswith("ary")) # False
```

### `count()`

Counts the occurrences of a character or substring.

```
name = "harry"
print(name.count("r"))  # 2
```

### `capitalize()`

Converts the first character to uppercase and the remaining characters to lowercase.

```
name = "hARRY"
print(name.capitalize())  # Harry
```

### `find()`

Returns the index of the first occurrence of a substring. If it is not found, it returns `-1`.

```
name = "harry"
print(name.find("rr"))  # 2
print(name.find("z"))   # -1
```

### `replace()`

Replaces all occurrences of a specified substring with another substring. It returns a new string.

```
name = "harry"
print(name.replace("r", "l"))  # hally
```

## Escape Sequence Characters

Escape sequences begin with a backslash (`\`) and represent special characters within a string.

|Escape sequence|Meaning|
|---|---|
|`\n`|Newline|
|`\t`|Horizontal tab|
|`\'`|Single quote|
|`\"`|Double quote|
|`\\`|Backslash|

Example:

```
print("Hello\nWorld")
# Hello
# World

print("Hello\tWorld")
# Hello    World

print('It\'s Python')
# It's Python

print("C:\\Users\\Harry")
# C:\Users\Harry
```

Escape sequences allow special characters to be included in strings without breaking their syntax.

## Important Notes

- Strings are immutable, meaning their individual characters cannot be changed directly.
    
- String indexing starts at `0`.
    
- The end index in slicing is excluded.
    
- String methods such as `replace()` return a new string rather than modifying the original.
    
- Python is case-sensitive, so `"Python"` and `"python"` are different strings.

## Overview

Python is a high-level programming language with simple, readable syntax. It is widely used for automation, file handling, networking, data analysis, and cybersecurity scripting.

## Writing Your First Python Program

Create a file named `hello.py`:

```
print("Hello World")
```

Run it using:

```
python3 hello.py
```

Output:

```
Hello World
```

The `print()` function displays information on the console.

## Printing and Variables

Variables store values that can be reused throughout a program.

```
ip_address = "192.168.1.10"
port = 443
service = "HTTPS"

print(f"Target: {ip_address}")
print(f"Port: {port}")
print(f"Service: {service}")
```

**f-strings** allow variables to be inserted directly into strings.

```
status = "Online"
print(f"Target {ip_address} is {status}")
```

### Variable Naming Rules

- Must start with a letter or underscore.
    
- Can contain letters, numbers, and underscores.
    
- Cannot start with a number or contain spaces.
    
- Names are case-sensitive.
    

```
target_ip = "10.0.0.5"
port_443 = 443
```

## Data Types and User Input

Python supports data types such as `str`, `int`, `float`, `bool`, and `list`.

```
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print(type(name))
print(type(age))
```

The `input()` function always returns a string unless you convert the value using functions such as `int()` or `float()`.

## Modules

Modules contain reusable Python code. Built-in modules are included with Python, while external packages usually require installation.

Examples of built-in modules include `os`, `sys`, `socket`, `json`, and `subprocess`.

```
import os
import socket

print(os.getcwd())
print(socket.gethostname())
```

The `os` module provides operating-system functionality, while `socket` provides networking capabilities.

External packages include Requests, Flask, Scapy, and BeautifulSoup.

## PIP and Virtual Environments

`pip` installs and manages Python packages.

```
python3 -m pip install requests
python3 -m pip list
python3 -m pip show requests
```

Create an isolated environment for project dependencies:

```
python3 -m venv venv
source venv/bin/activate
```

On Windows:

```
venv\Scripts\activate
```

Store dependencies in `requirements.txt` and install them using:

```
python3 -m pip install -r requirements.txt
```

## Python REPL

REPL stands for Read-Evaluate-Print Loop. It allows you to execute Python expressions interactively.

```
>>> 10 + 5
15
>>> 20 * 3
60
>>> 17 % 5
2
>>> 2 ** 8
256
```

Start it with `python3` and exit using `exit()`.

## Comments and Docstrings

Comments explain code and are ignored by Python.

```
# Store the target address
target_ip = "192.168.1.10"
port = 443  # HTTPS port
```

Use triple-quoted docstrings to document functions:

```
def check_target(target):
    """Display target information."""
    print(f"Target: {target}")
```

## Combining Concepts

```
import socket

# Store target information
target = "192.168.1.10"
ports = [22, 80, 443]

print(f"Hostname: {socket.gethostname()}")

for port in ports:
    print(f"Target: {target}:{port}")
```

This example combines modules, variables, lists, loops, comments, and f-strings.

## Handling Sensitive Information

Avoid hardcoding passwords, API keys, and authentication tokens in source code. Use environment variables or dedicated secret-management solutions for sensitive values.

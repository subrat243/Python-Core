## Overview

Python is a high-level programming language with a simple and readable syntax. It can be used to automate repetitive tasks, process system information, work with files and networks, analyze data, and build custom tools.

This chapter covers some of the fundamental concepts required to start writing Python scripts.

## Writing Your First Python Program

Create a file named `hello.py`:

```
print("Hello World")
```

Run the program from the terminal:

```
python hello.py
```

On many Linux systems, you may use:

```
python3 hello.py
```

Output:

```
Hello World
```

`print()` is a built-in Python function used to display information on the console.

---

## Printing in Python

The `print()` function is used to display information on the console.

It is useful for displaying results, status messages, scan information, logs, and other program output.

```Python
print("System check started")
print("Target system detected")
```

Output:

```text
System check started
Target system detected
```

Multiple values can also be printed:

```Python
ip_address = "192.168.1.10"
port = 443

print("Target:", ip_address)
print("Port:", port)
```

Output:

```text
Target: 192.168.1.10
Port: 443
```

## Variables in Python

A variable is a name used to store a value.

Variables are useful when working with information such as IP addresses, ports, usernames, file paths, URLs, or configuration values.

For example:

```Python
ip_address = "192.168.1.10"
port = 22
service = "SSH"

print("Target:", ip_address)
print("Port:", port)
print("Service:", service)
```

Output:

```text
Target: 192.168.1.10
Port: 22
Service: SSH
```

Instead of repeatedly writing the same IP address or port number, we can store them in variables and reference them whenever required.

### Variable Naming Rules

Variable names:

- Must start with a letter or `_`
    
- Can contain letters, numbers, and `_`
    
- Cannot start with a number
    
- Cannot contain spaces or `-`
    
- Are case-sensitive
    

Valid examples:

```Python
target_ip = "10.0.0.5"
username_list = ["admin", "root"]
port_443 = 443
```

Invalid examples:

```text
1ip = "10.0.0.5"
user-name = "admin"
```

`1ip` starts with a number, while `user-name` contains a hyphen.

Python treats uppercase and lowercase names as different variables:

```Python
ip = "192.168.1.10"
IP = "10.0.0.5"

print(ip)
print(IP)
```

## Dynamic Output with f-Strings

f-strings allow variables to be inserted directly into a string.

```Python
ip = "10.10.10.5"
port = 443

print(f"Connecting to {ip} on port {port}")
```

Output:

```text
Connecting to 10.10.10.5 on port 443
```

They are useful when generating dynamic messages:

```Python
target = "10.10.10.5"
status = "Online"

print(f"Target {target} is {status}")
```

Output:

```text
Target 10.10.10.5 is Online
```

## Modules

A module is a Python file containing reusable code.

Modules allow us to use functionality that has already been written instead of implementing everything from scratch.

Python provides many built-in modules.

For example, the `os` module can be used to interact with the operating system:

```
import os

print(os.getcwd())
```

This displays the current working directory.

Another example is the `socket` module:

```
import socket

hostname = socket.gethostname()
print(f"Hostname: {hostname}")
```

Modules can make scripts much more useful by providing additional functionality.

---

## Types of Modules

Python modules can generally be divided into two categories.

### Built-in Modules

These are included with Python and normally do not require separate installation.

Examples include:

```
os
sys
socket
random
json
subprocess
```

Example:

```
import random

number = random.randint(1, 100)
print(f"Generated number: {number}")
```

### External Modules

External modules are developed separately from the Python standard library and usually need to be installed before they can be imported.

Examples include:

```
Flask
Requests
Scapy
BeautifulSoup
```

Once installed, they can be imported into a program:

```
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

Only interact with systems and URLs you are authorized to test.

## PIP

`pip` is Python's package installer. It is commonly used to install external Python packages.

For example:

```
pip install flask
```

On some systems:

```
pip3 install flask
```

After installation, the package can be imported:

```
import flask
```

You can also install a specific package version:

```
pip install flask==3.1.2
```

To see installed packages:

```
pip list
```

To display information about a package:

```
pip show flask
```

For projects, it is common to store dependencies in a `requirements.txt` file:

```
requests
flask
scapy
```

Install them with:

```
pip install -r requirements.txt
```

Using a virtual environment is recommended for projects so that dependencies remain isolated:

```
python3 -m venv venv
source venv/bin/activate
```

On Windows:

```
venv\Scripts\activate
```

## Using Python as a Calculator

Python can also be used directly from the terminal as a calculator.

Start the Python interpreter:

```
python3
```

You will enter the Python REPL, which stands for:

```
Read
Evaluate
Print
Loop
```

Example:

```
>>> 10 + 5
15

>>> 20 * 3
60

>>> 100 / 4
25.0

>>> 2 ** 8
256
```

The REPL is useful for quickly testing Python expressions, functions, and small pieces of code.

Exit the REPL with:

```
exit()
```

## Comments

Comments are text written inside source code that Python does not execute.

Comments help explain what a piece of code does, document configuration, or leave notes for other developers.

A single-line comment starts with `#`:

```
# Store the target IP address
target_ip = "192.168.1.10"

print(target_ip)
```

Python ignores everything after `#` on that line.

Comments can also be placed after code:

```
port = 443  # HTTPS port
```

---

## Multi-Line Comments

Python does not have a dedicated multi-line comment syntax.

Multiple single-line comments can be used:

```
# This script stores target information.
# The values can be reused throughout
# the rest of the program.

target_ip = "192.168.1.10"
```

Triple-quoted strings are also commonly used for documentation or multi-line text:

```
"""
This script demonstrates
basic Python concepts.
"""

print("Python basics")
```

For documenting functions and classes, triple-quoted strings are commonly used as docstrings:

```
def scan_target(target):
    """Process information for a target."""
    print(f"Target: {target}")
```

## Combining the Concepts

The following example combines variables, printing, modules, comments, and dynamic output:

```
import socket

# Store target information
target_ip = "192.168.1.10"
ports = [22, 80, 443]

# Get local hostname
hostname = socket.gethostname()

print(f"Hostname: {hostname}")
print(f"Target: {target_ip}")

for port in ports:
    print(f"Checking {target_ip}:{port}")
```

Example output:

```
Hostname: kali
Target: 192.168.1.10
Checking 192.168.1.10:22
Checking 192.168.1.10:80
Checking 192.168.1.10:443
```

This demonstrates how simple Python features can be combined to create reusable scripts.

## Handling Sensitive Information

Avoid hardcoding real passwords, API keys, authentication tokens, or other secrets directly inside source code.

Avoid:

```
username = "admin"
password = "real_password"
```

For real projects, sensitive values should be stored using safer approaches such as environment variables or dedicated secret-management solutions.

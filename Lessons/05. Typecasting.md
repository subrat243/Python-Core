## Overview

Typecasting is the process of converting a value from one data type into another. Python supports implicit type conversion and explicit typecasting.

## Implicit Type Conversion

Python automatically converts certain values to compatible types during operations.

```python
number = 80
timeout = 0.5

result = number + timeout

print(result)
print(type(result))
```

Output:

```text
80.5
<class 'float'>
```

Python converts the integer `80` to a compatible floating-point value during the operation. The result is a float.

## Explicit Typecasting

Explicit typecasting involves manually converting a value using built-in functions.

|Function|Purpose|Example|
|---|---|---|
|`int()`|Convert to integer|`int("443")`|
|`float()`|Convert to float|`float("2.5")`|
|`str()`|Convert to string|`str(443)`|
|`bool()`|Convert to Boolean|`bool(1)`|
|`list()`|Convert to list|`list("abc")`|
|`tuple()`|Convert to tuple|`tuple([1, 2])`|
|`set()`|Convert to set|`set([1, 1, 2])`|
|`bytes()`|Create a bytes object|`bytes([65, 66])`|

## Integer to String

```python
port = 443
port_text = str(port)

print(port_text)
print(type(port_text))
```

Output:

```text
443
<class 'str'>
```

This is useful when combining numeric values with text or writing data into text-based files.

## String to Integer

```python
port_text = "443"
port = int(port_text)

print(port)
print(type(port))
```

Output:

```text
443
<class 'int'>
```

An invalid numeric string raises a `ValueError`.

```python
port = int("abc")
```

## Integer to Float

```python
latency = 32
latency_seconds = float(latency)

print(latency_seconds)
print(type(latency_seconds))
```

Output:

```text
32.0
<class 'float'>
```

## String and Bytes Conversion

Strings can be converted into bytes using `.encode()`, while bytes can be converted into strings using `.decode()`.

```python
message = "GET / HTTP/1.1"

encoded = message.encode("utf-8")
decoded = encoded.decode("utf-8")

print(encoded)
print(decoded)
```

Output:

```text
b'GET / HTTP/1.1'
GET / HTTP/1.1
```

These operations are useful when processing files, network requests, and raw protocol data.

## Hexadecimal Conversion

The `hex()` function converts an integer into a hexadecimal string.

```python
number = 255

hex_value = hex(number)
restored = int(hex_value, 16)

print(hex_value)
print(restored)
```

Output:

```text
0xff
255
```

## Key Takeaways

- Typecasting converts values between data types.
    
- Implicit conversion occurs automatically in certain operations.
    
- Explicit conversion uses functions such as `int()`, `float()`, and `str()`.
    
- `.encode()` and `.decode()` convert between strings and bytes.
    
- Invalid conversions may raise exceptions, so input should be validated.


## Overview

User input allows a program to receive data from a user through the keyboard. Python uses the built-in `input()` function for this purpose.

### The `input()` Function

```python
name = input("Enter username: ")

print(f"Username: {name}")
```

Example:

```text
Enter username: admin
Username: admin
```

The entered value is stored in the variable `name`.

## Important Rule: Input Always Returns a String

Even when the user enters a number, `input()` returns it as a string.

```python
port = input("Enter port: ")

print(type(port))
```

If the user enters `443`, the output is:

```text
<class 'str'>
```

To process the port as an integer, convert the input explicitly.

```python
port = int(input("Enter port: "))

print(port)
print(type(port))
```

Output:

```text
443
<class 'int'>
```

## Taking Multiple Inputs

```python
target = input("Enter target IP: ")
port = int(input("Enter port: "))

print(f"Target: {target}")
print(f"Port: {port}")
```

Example:

```text
Enter target IP: 192.168.1.10
Enter port: 443
Target: 192.168.1.10
Port: 443
```

The target IP remains a string because it represents an address, while the port is converted into an integer.

## Validating User Input

Direct conversion can cause an error if the user enters invalid data. Use `try` and `except` to handle conversion errors.

```python
try:
    port = int(input("Enter port: "))

    if 1 <= port <= 65535:
        print(f"Valid port: {port}")
    else:
        print("Port must be between 1 and 65535")

except ValueError:
    print("Please enter a valid integer")
```

Example with invalid input:

```text
Enter port: abc
Please enter a valid integer
```

The `try` block attempts the conversion. If `int()` raises a `ValueError`, the `except` block handles it instead of allowing the program to terminate unexpectedly.

## Practical Example: Target and Port Input

```python
target = input("Enter target IP: ").strip()
port_text = input("Enter port: ").strip()

try:
    port = int(port_text)

    if not 1 <= port <= 65535:
        print("Invalid port range")
    else:
        print(f"Target: {target}")
        print(f"Port: {port}")
        print(f"Port data type: {type(port)}")

except ValueError:
    print("Invalid port. Enter a whole number.")
```

This example removes surrounding whitespace, converts the port to an integer, checks its valid range, and handles invalid numeric input.

Note that this validates the port range, not whether the target is a valid IP address. Additional validation is required for that.

## Key Takeaways

- `input()` receives data from the keyboard.
    
- `input()` always returns a string.
    
- Use typecasting when a different data type is required.
    
- Use `try` and `except` to handle invalid conversions.
    
- Validate user input before using it in network tools or other security-related scripts.

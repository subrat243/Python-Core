## Overview

Python programs frequently receive and process different kinds of data. A value may begin as a string and later need to be converted into an integer, float, or bytes before it can be processed correctly.

This is especially common when working with ports, addresses, logs, command-line input, configuration values, raw network data, and tool output.

## `type()` Function

The `type()` function is used to determine the data type of a value or variable.

```
a = 31
print(type(a))
```

Output:

```
<class 'int'>
```

A value enclosed in quotes is a string:

```
b = "31"
print(type(b))
```

Output:

```
<class 'str'>
```

Although `31` and `"31"` look similar, Python treats them differently.

```
number = 31
text = "31"

print(type(number))
print(type(text))
```

Output:

```
<class 'int'>
<class 'str'>
```

The first value is an integer, while the second is a string.

---

## What is Typecasting?

Typecasting means converting a value from one data type into another.

For example:

```
port = "443"

print(type(port))

port = int(port)

print(type(port))
```

Output:

```
<class 'str'>
<class 'int'>
```

This is useful when data comes from a file, user input, logs, or another program and needs to be processed as a different type.

---

## Implicit Type Conversion

Python can automatically convert numeric values to a compatible type when performing certain operations.

For example:

```
port = 80
timeout = 0.5

result = port + timeout

print(result)
print(type(result))
```

Output:

```
80.5
<class 'float'>
```

Here, the integer `80` is combined with the float `0.5`, and the resulting value is a float.

This is known as implicit type conversion.

---

## Explicit Typecasting

Explicit typecasting means manually converting a value using Python's built-in functions.

Common conversion functions include:

```
int()
float()
str()
bool()
list()
tuple()
set()
bytes()
```

### Integer to String

```
port = 443

port_text = str(port)

print(port_text)
print(type(port_text))
```

Output:

```
443
<class 'str'>
```

This is useful when a numeric value needs to be combined with text or written into a text-based format.

---

## String to Integer

A string containing a valid number can be converted into an integer.

```
port_text = "443"

port = int(port_text)

print(port)
print(type(port))
```

Output:

```
443
<class 'int'>
```

This is useful when a port number is read from a configuration file or user input.

An invalid value cannot be converted:

```
port = int("abc")
```

This produces:

```
ValueError
```

Therefore, external input should be validated before conversion.

---

## Integer to Float

An integer can be converted into a floating-point number:

```
value = 32

result = float(value)

print(result)
print(type(result))
```

Output:

```
32.0
<class 'float'>
```

This can be useful when working with measurements such as response times or latency.

---

## User Input with `input()`

The `input()` function allows a user to enter data through the keyboard.

```
name = input("Enter username: ")

print(f"Username: {name}")
```

If the user enters:

```
admin
```

The output is:

```
Username: admin
```

An important point is that `input()` always returns a string.

For example:

```
port = input("Enter port: ")

print(type(port))
```

If the user enters:

```
443
```

The result is still:

```
<class 'str'>
```

The value must be converted if an integer is required.

```
port = int(input("Enter port: "))

print(type(port))
```

Now entering `443` produces:

```
<class 'int'>
```

## Processing Multiple Inputs

Typecasting becomes useful when collecting several values.

```
target = input("Enter target IP: ")
port = int(input("Enter port: "))

print(f"Target: {target}")
print(f"Port: {port}")
```

Example:

```
Enter target IP: 192.168.1.10
Enter port: 443
Target: 192.168.1.10
Port: 443
```

The IP address remains a string because it is text, while the port is converted to an integer for numeric processing.

## Converting Strings to Bytes

Raw data is often represented using the `bytes` type.

A string can be converted into bytes using `.encode()`:

```
payload = "admin:password123"

encoded = payload.encode("utf-8")

print(encoded)
print(type(encoded))
```

Output:

```
b'admin:password123'
<class 'bytes'>
```

The reverse operation uses `.decode()`:

```
data = b"GET /index.html HTTP/1.1"

decoded = data.decode("utf-8")

print(decoded)
print(type(decoded))
```

Output:

```
GET /index.html HTTP/1.1
<class 'str'>
```

This conversion is useful when processing raw requests, files, encoded data, and network communication.

---

## IP Address Conversion

Python's `socket` module provides functions for converting IP addresses into binary representations.

```
import socket

ip = "192.168.1.10"

ip_bytes = socket.inet_aton(ip)

print(ip_bytes)
```

Output:

```
b'\xc0\xa8\x01\n'
```

The result is a byte representation of the IPv4 address.

## Parsing Log Data

Log entries often contain numbers as strings.

For example:

```
log_entry = "Connection attempt on port 22"

port_text = log_entry.split()[-1]
port = int(port_text)

print(port)
print(type(port))
```

Output:

```
22
<class 'int'>
```

The string value `"22"` is converted into the integer `22`, allowing numerical comparisons:

```
if port == 22:
    print("SSH port detected")
```

## Hexadecimal Conversion

Python can convert integers into hexadecimal strings using `hex()`.

```
data = 12345

hex_data = hex(data)

print(hex_data)
```

Output:

```
0x3039
```

The hexadecimal value can be converted back into an integer:

```
restored = int(hex_data, 16)

print(restored)
```

Output:

```
12345
```

Hexadecimal representations are commonly encountered when examining binary data, memory values, file contents, and packet data.

## Validating Input Before Typecasting

Directly converting user input can cause errors if the value is invalid.

For example:

```
port = int(input("Enter port: "))
```

If the user enters:

```
abc
```

Python raises a `ValueError`.

A safer approach is to handle invalid input:

```
port_text = input("Enter port: ")

if port_text.isdigit():
    port = int(port_text)
    print(f"Port: {port}")
else:
    print("Invalid port number")
```

This prevents invalid text from being passed directly to `int()`.

For more robust programs, `try` and `except` can be used:

```
try:
    port = int(input("Enter port: "))
    print(f"Port: {port}")
except ValueError:
    print("Please enter a valid number")
```

|Conversion|Example|Result|
|---|---|---|
|String → Integer|`int("443")`|`443`|
|Integer → String|`str(443)`|`"443"`|
|Integer → Float|`float(32)`|`32.0`|
|String → Float|`float("0.53")`|`0.53`|
|String → Bytes|`"data".encode()`|`b"data"`|
|Bytes → String|`b"data".decode()`|`"data"`|
|Integer → Hex|`hex(255)`|`"0xff"`|
|Hex → Integer|`int("0xff", 16)`|`255`|

## Practical Example

The following example combines `input()`, `type()`, typecasting, validation, and dynamic output:

```
target = input("Enter target IP: ")
port_text = input("Enter port: ")

if port_text.isdigit():
    port = int(port_text)

    print(f"Target: {target}")
    print(f"Port: {port}")
    print(f"Port data type: {type(port)}")
else:
    print("Invalid port")
```

Example:

```
Enter target IP: 192.168.1.10
Enter port: 443
Target: 192.168.1.10
Port: 443
Port data type: <class 'int'>
```

Here, `target` remains a string while `port_text` is converted from a string into an integer.

## Key Takeaways

- `type()` is used to identify the data type of a value.
    
- `input()` always returns user input as a string.
    
- Typecasting converts a value from one type to another.
    
- `int()` converts valid numeric values into integers.
    
- `float()` converts values into floating-point numbers.
    
- `str()` converts values into strings.
    
- `.encode()` converts strings into bytes.
    
- `.decode()` converts bytes into strings.
    
- `hex()` converts integers into hexadecimal representation.
    
- External input should be validated before typecasting.
    
- `try` and `except` can be used to handle conversion errors safely.
    

Understanding type checking and typecasting is important when processing input from users, files, logs, commands, network data, and other external sources.

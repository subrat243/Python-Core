## Overview

Type checking is the process of identifying the data type of a value or variable. Python provides the built-in `type()` function to determine whether a value is an integer, string, float, or another data type.

## The `type()` Function

```python
a = 31
b = "31"
c = 3.14

print(type(a))
print(type(b))
print(type(c))
```

Output:

```text
<class 'int'>
<class 'str'>
<class 'float'>
```

Although `31` and `"31"` look similar, Python treats them differently. The first is an integer, while the second is a string because it is enclosed in quotes.

## Common Data Types

|Data type|Example|Description|
|---|---|---|
|`int`|`31`|Whole numbers|
|`float`|`3.14`|Decimal numbers|
|`str`|`"hello"`|Text|
|`bool`|`True`|Boolean values|
|`list`|`[1, 2, 3]`|Ordered, mutable collection|
|`tuple`|`(1, 2, 3)`|Ordered, immutable collection|
|`set`|`{1, 2, 3}`|Collection of unique elements|
|`dict`|`{"port": 443}`|Key-value pairs|
|`bytes`|`b"data"`|Sequence of bytes|

## Type Checking in Practice

```python
port = 443
username = "admin"

if type(port) == int:
    print("Port is an integer")

if type(username) == str:
    print("Username is a string")
```

Output:

```text
Port is an integer
Username is a string
```

Python also provides `isinstance()` to check whether a value belongs to a particular type.

```python
port = 443

print(isinstance(port, int))
print(isinstance(port, str))
```

Output:

```text
True
False
```

`isinstance()` is generally preferred when checking types because it also supports inheritance.

## Practical Example: Checking Port Data

```python
port = "443"

if isinstance(port, int):
    print("Ready for numeric processing")
else:
    print("Port is not an integer")
```

Output:

```text
Port is not an integer
```

This is useful when processing configuration values, log entries, and command output that may contain numbers represented as strings.

## Key Takeaways

- `type()` identifies the type of a value.
    
- `isinstance()` checks whether a value belongs to a specified type.
    
- `"443"` is a string, whereas `443` is an integer.
    
- Type checking helps identify unexpected data before processing it.

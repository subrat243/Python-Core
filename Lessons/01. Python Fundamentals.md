## What is Python?

Python is a high-level, interpreted programming language with a simple and readable syntax. It is useful for writing scripts that automate tasks, process information, interact with systems, work with networks, and handle large amounts of data.

## What is Programming?

Just as humans use languages such as Hindi or English to communicate, programming languages allow us to communicate instructions to a computer.

Programming is the process of writing instructions that tell a computer what to do.

For example:

```
print("Hello, World!")
```

Output:

```
Hello, World!
```

The `print()` function tells Python to display the specified text on the screen.

---

## What is Python?

Python is a high-level programming language designed to make code easier to read and write. Its syntax is relatively close to natural language, making it suitable for beginners as well as larger projects.

Python is commonly used for:

- Automation and scripting
    
- System administration
    
- Network programming
    
- Data processing
    
- Web development
    
- Machine learning
    
- Building custom tools
    

Its large ecosystem also provides many libraries for interacting with operating systems, networks, files, APIs, and other services.

---

## Features of Python

### Easy to Understand

Python has a clean and readable syntax.

```
target = "192.168.1.10"
print(target)
```

This makes scripts easier to write, read, and maintain.

### Free and Open Source

Python is freely available and can be used across personal, educational, and commercial projects.

### High-Level Language

Python handles many low-level operations internally, allowing the programmer to focus on the logic of the program.

### Portable

Python programs can run on Linux, Windows, and macOS with the required Python installation and dependencies.

### Large Ecosystem

Python provides a large collection of built-in modules and external packages that can extend the functionality of a script.

## Installing Python

Python can be downloaded from the official website:

[Python Official Website](https://www.python.org/?utm_source=chatgpt.com)

After installation, verify the version from the terminal:

```
python3 --version
```

Example:

```
Python 3.13.7
```

On some systems, the command is:

```
python --version
```

---

## Your First Python Program

Create a file called `hello.py`:

```
print("Hello World")
```

Run it from the terminal:

```
python hello.py
```

On many Linux systems:

```
python3 hello.py
```

Output:

```
Hello World
```

Python files normally use the `.py` extension.
